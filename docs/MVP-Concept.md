Upstage의 **Solar Pro API**와 **LangGraph**를 활용한 국내 여행 스케줄링 서비스, \*\*"Solar-Travel Planner (가칭)"\*\*의 MVP(Minimum Viable Product) 제작을 위한 \*\*PRD(제품 요구사항 정의서)\*\*입니다.

## ---

**1\. 프로젝트 개요**

* **프로젝트명:** Solar-Travel Planner  
* **목적:** 사용자가 입력한 기간과 지역에 맞춰 Solar Pro가 큐레이션한 3가지 테마의 일정을 제공하고, 최종 선택안을 구글 문서로 자동화하여 제공함.  
* **타겟 사용자:** 여행 계획 수립에 번거로움을 느끼지만, 본인의 취향(테마)은 반영하고 싶은 국내 여행객.  
* **핵심 기술:** Solar Pro API (LLM), LangGraph (Workflow), Google Docs API (Automation), TourAPI 4.0 (Data).

## ---

**2\. 주요 기능 (User Stories)**

### **2.1 대화형 정보 수집**

* **기능:** 챗봇 UI를 통해 여행지(도/시 단위)와 기간(N박 M일)을 입력받음.  
* **사용자 스토리:** "나는 여행지와 날짜를 입력하여 나에게 맞는 계획을 추천받고 싶다."

### **2.2 테마별 3종 스케줄 제안**

* **기능:** Solar Pro를 이용해 '시그니처', '감성/트렌드', '힐링/여유' 3가지 테마의 일정을 생성.  
* **상세:** 각 일정에는 명소와 맛집이 포함되어야 하며, 장소별 상세 페이지 링크(네이버/카카오 지도 등)가 제공됨.

### **2.3 구글 문서(Google Docs) 내보내기**

* **기능:** 사용자가 선택한 최종 일정을 구글 문서의 테이블 형태로 자동 생성.  
* **상세:** 깔끔한 레이아웃과 클릭 가능한 하이퍼링크 포함.

## ---

**3\. 기술적 요구사항 (Technical Requirements)**

### **3.1 모델 및 워크플로우**

* **LLM:** **Upstage Solar Pro API** (모든 추론 및 텍스트 생성 담당).  
* **Orchestration:** **LangGraph** (상태 관리 및 병렬 노드 처리).  
* **RAG:** BM25 및 벡터 검색을 활용한 하이브리드 검색 (국내 관광지 데이터베이스 연동).

### **3.2 데이터 및 API**

* **관광 정보:** 한국관광공사 **TourAPI 4.0** (공식 데이터 확보).  
* **외부 링크:** Tavily 또는 Google Search를 활용한 최신 지도/웹사이트 URL 수집.  
* **문서화:** **Google Docs API** (OAuth 2.0 인증 및 문서 생성).

## ---

**4\. 제품 설계 (Product Design)**

### **4.1 LangGraph 노드 설계**

1. **Node\_Analyze:** 사용자 의도 파악 및 검색 쿼리 최적화.  
2. **Node\_Search:** 외부 API 연동을 통한 장소 후보군 확보.  
3. **Node\_Plan (Parallel):** Solar Pro를 이용한 3개 테마 병렬 생성.  
4. **Node\_Wait:** 사용자 선택을 위한 인터럽트(Interrupt).  
5. **Node\_Export:** 최종 선택본을 Google Docs HTML로 변환 및 전송.

### **4.2 UI/UX 컴포넌트**

* **채팅창:** 메시지 스트리밍 지원.  
* **일정 카드:** 3가지 제안을 가로 슬라이드로 비교 가능한 카드 형태.  
* **링크 칩:** 클릭 시 바로 지도로 연결되는 버튼형 링크.

## ---

**5\. 단계별 개발 계획 (Roadmap)**

| 단계 | 목표 | 주요 작업 |
| :---- | :---- | :---- |
| **1단계** | **Core Logic** | Solar Pro API 연동 및 LangGraph 기본 워크플로우(1개 일정) 구축 |
| **2단계** | **Multi-Theme** | 병렬 노드 구현을 통한 3가지 테마 생성 및 UI 카드 레이아웃 적용 |
| **3단계** | **Link & Doc** | 장소별 실시간 링크 수집 및 Google Docs API 테이블 생성 연동 |
| **4단계** | **QA & MVP** | 예외 처리(폐업 장소 등), 속도 최적화 및 최종 배포 |

## ---

**6\. 성공 지표 (Success Metrics)**

* **정확도:** 추천된 장소 중 실제 존재하는 장소 비율 100%.  
* **사용성:** 초기 입력부터 구글 문서 생성 완료까지의 단계 최소화.  
* **품질:** Solar Pro가 생성한 가이드 텍스트의 자연스러움 및 한국어 특화 정보의 깊이.
